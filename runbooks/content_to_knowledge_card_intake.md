# Content to Knowledge Card Intake Runbook

Applies to social posts, tool explainers, model news, course ideas, and creative
workflow posts.

## Steps

1. Identify source type and topic.
2. Mark verification status.
3. Extract core idea.
4. Classify output type: content, SOP, course module, business offer, agent
   rule, or technical task.
5. Record blocked claims and publish prerequisites.
6. Create a knowledge card before long-term memory or public content use.

## Publish Gate

Do not publish vendor/model/news claims until a primary source check and Thai
spelling review are complete.
