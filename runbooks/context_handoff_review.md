# Context Handoff Review Runbook

Applies to `/handoff`-style continuation files.

## Handoff Contents

Include only:

- current mission and packet
- changed files
- validation evidence
- blockers
- next gate
- required skills or runbooks

Exclude:

- secrets
- `.env` values
- browser cookies
- raw customer data
- full chat history
- full repo dumps

## Review

External handoff skills require source review and receipt before installation.
