# Creator Signal Map

Use this map to translate public creator observations into SIRINX-safe content ideas.

| Signal | Meaning | Allowed output |
| --- | --- | --- |
| AI workflow | A repeatable agent/operator pattern | Original SIRINX workflow note |
| Developer tooling | CLI, repo, plugin, MCP, or automation interface idea | Local implementation checklist |
| Product shipping | Launch, MVP, SaaS, build-in-public pattern | SIRINX product delivery habit |
| Growth system | Funnel, campaign, community, ROAS, positioning | Ethical campaign hypothesis |
| Design storytelling | UX, visual system, interface narrative | Original design brief |
| Prompt pattern | Prompt structure or reusable command shape | SIRINX-specific prompt template |
| Market observation | Category, pricing, trend, or competitor signal | Research note requiring source verification |

Every signal requires human review before becoming public content.
