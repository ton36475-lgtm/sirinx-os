# Local Business Promo Prompt Pack

Reusable public-marketing prompt pack for small local business assets.

## Projects

- `เฮียซูมซาลาเปา`
- `ข้าวหมูแดงลุงแบงค์ เตาถ่าน`
- `ตามเมียสั่ง`
- `tree_sale_yangna`

## Output Types

- 1 poster prompt per project.
- 1 social media prompt per project.
- Thai text lock manifest per project.
- Public marketing checklist.

## Rules

- Keep text exactly as locked in `packages/asset-registry/local-business/text-locks.json`.
- Public marketing only.
- Do not include private system details, fake chat UI, internal dashboards, or hidden operations.
- Do not use cyberpunk, cartoon, or anime styles unless a later owner-approved packet explicitly requests it.
- Do not run paid image generation without a separate gate.
