# AI Creator Signal Map

SIRINX uses creator radar as a research input, not as an automation target.

Implementation contract:

- Seed accounts live in `packages/content-factory/src/intelligence/xAccounts.mjs`.
- Weekly radar generation is local-only and manual-observation based.
- Signal classification is deterministic and review-gated.
- Output is inspiration, not copied text.
- Public posts can be summarized only at a high level with source links.

Primary signals:

```text
ai_workflow
developer_tooling
product_shipping
growth_system
design_storytelling
prompt_pattern
market_observation
unknown
```
