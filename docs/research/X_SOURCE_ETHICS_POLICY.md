# X Source Ethics Policy

Allowed:

- Manual review of public account pages.
- High-level signal extraction.
- Original SIRINX content derived from a pattern, not copied wording.
- Source URL logging.
- Human review before publication.

Blocked:

- Private data scraping.
- Automated X scraping or posting.
- Impersonation.
- Fake quotes.
- Fake endorsement claims.
- Copying full posts into SIRINX content.
- Using internal labels as factual public titles.

Default state:

```text
LOCAL ONLY — NO X AUTOMATION — HUMAN REVIEW REQUIRED
```
