# Source Selection Checklist

Use this before recording competitor evidence.

## Allowed Public Sources

- Official website pages
- Public pricing pages
- Public documentation
- Public blog posts
- Public changelogs
- Public social posts
- Public app store listings
- Public press releases
- Public case studies

## Required Source Metadata

- Source URL or citation note
- Capture date
- Source owner
- Source type
- Reliability level: high, medium, low
- What claim was observed
- Whether the claim is directly visible or inferred

## Blocked Sources

- Login-only dashboards
- Private communities
- Customer records
- Leaked datasets
- Credentialed systems
- Bot bypass, antibot bypass, stealth scraping, or de-anonymization

## Decision Rule

If a source requires credentials, evasion, private identity linkage, or non-public access, exclude it and record the exclusion reason.
