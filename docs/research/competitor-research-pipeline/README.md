# Competitor Research Pipeline

Status: local research template only. No external scan, scraping, credential access, or de-anonymization is authorized.

## Purpose

Create a repeatable way to turn public competitor observations into a strategy-ready Build Packet.

## Workflow

1. Select public sources.
2. Record source reliability and capture date.
3. Score features, pricing, positioning, trust signals, content strategy, and integration depth.
4. Fill the SWOT template.
5. Produce a Build Packet with opportunities, risks, and next build actions.

## Files

- `source_selection_checklist.md`
- `scoring_matrix_template.csv`
- `swot_template.md`
- `sample_build_packet.md`
- `validate_competitor_research_packet.mjs`

## Guardrails

- Public sources only.
- No unauthorized third-party scanning.
- No login walls, private dashboards, customer data, or credentialed systems.
- No stealth browser, antibot bypass, or de-anonymization.
- Output is research notes and Build Packet only.
