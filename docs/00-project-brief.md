# Project Brief

## Objective
Standardize SIRINXDev work around Hermes Spec-First Swarm Protocol v1.

## Core Workflow

```text
Prompt -> Requirement -> Context Memory -> Spec -> Approval -> Code -> Test -> Report
```

## Non-Workflow

```text
Prompt -> Code immediately
```

## Operating Rules
- No Spec, No Code.
- No Context, No Memory.
- No Approval, No Execution.
- No Test, No Completion Claim.

## Approval Phrase

```text
APPROVE_IMPLEMENTATION
```

## Stop Point

```text
HERMES SPEC-FIRST SWARM READY - LIVE LOCAL STATE - WAITING FOR APPROVE_IMPLEMENTATION
```
