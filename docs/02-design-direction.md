# Design Direction

## Dashboard Placement
Place the Hermes Spec-First Swarm panel near the Gateway / Team Runtime area so it reads as a governing workflow, not a separate app.

## UI Pattern
Use existing Developer Command Center patterns:
- panel header
- status pill
- summary cards
- stop point banner
- signal lists

## Content Rules
- Use compact operational labels.
- Prefer status, phase, role, evidence, and blocked-action language.
- Do not add executable buttons.

## Visual QA
- The panel must fit the existing dashboard grid.
- Text must wrap inside cards and signal rows.
- The approval phrase must be visible without opening a modal.
