# Operating Rules

## Allowed Local Work

- Create and edit local docs, CSV, JSON, HTML, JS, CSS, and reports.
- Draft original prompts and listing copy.
- Generate mock data.
- Run local validation scripts.
- Write local receipts and checksums.

## Blocked Work

- Live Amazon Merch publishing.
- Amazon control bypass, scraping, or upload spam.
- Paid provider calls.
- Secret or credential reading.
- Customer messaging or public broadcast.
- Push, deploy, migration, or cloud mutation.
- Infringing concepts, celebrity likeness, brand confusion, sports team references, fake reviews, or fake traffic.

## IP Guardian Rules

- Red risk blocks the concept.
- Yellow risk requires revision before design.
- Green means local draft can continue, not legal clearance.
- Every final publish decision remains owner action.

## Quality Rules

- Text must be readable on target products.
- Artwork must be original, clean, high contrast, and product-fit.
- Listing copy must be natural language, not keyword stuffing.
- Traffic content must be manually posted and must not promise income.
