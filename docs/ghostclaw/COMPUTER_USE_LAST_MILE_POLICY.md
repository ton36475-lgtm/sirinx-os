# Computer Use Last-Mile Policy

Mission ID: `GC-CLICKUP-SINGLE-INBOX-WEEKLY-SYNC-20260630-002`

## Role

Computer-use is a last-mile visual smoke tool only. The bridge prefers local
file-bus packets and API-safe dry-runs over UI clicking.

## Allowed

- inspect visible local UI state
- verify ClickUp mirror visually if the browser is already logged in
- capture local screenshot or status evidence when needed

## Forbidden

- type or paste secrets
- click delete
- invite users
- change workspace settings
- approve external mutation dialogs
- bypass permission prompts

No computer-use action is required for the local dry-run artifacts in this
mission.
