# @sirinx/autoglow-core

Shared local core for AGM AUTOGLOW.

## Scope

- Project, scene, asset, and platform types.
- Safe workflow constants.
- Project validation.
- Scene prompt compilation.
- Markdown and CSV delivery-pack export.

## Boundary

This package does not call providers, publish content, automate Google Flow, or read browser credentials. It only prepares human-reviewed creative production assets.

## Verify

```bash
pnpm autoglow:test
```
