# Proposal - P000A Repo Intake Readonly

Change ID: `gc-sf-re-os-v1-p000a`  
Mission: `GC-SF-RE-OS-V1-20260701-001`

## Problem

GhostClaw/Hermes planning has accumulated many related but scattered plans:
Hermes, Codex, AI Second Brain, OpenSpec, 9Router, The Agency, Logto, n8n,
video-use, OpenClaw, validation, receipt, and handoff lanes. Without a single
master operating loop, execution pressure can drift toward install-all,
provider calls, live connectors, or source mutation before source verification
and spec acceptance.

## Proposed Change

Lock `GHOSTCLAW_SENIOR_FULLSTACK_REVERSE_ENGINEERING_OS_V1` as the only master
plan and start with `P000A_REPO_INTAKE_READONLY`.

The first packet produces:

- source list
- source reliability table
- open questions
- repo intake canvas
- reverse engineering canvas
- OpenSpec entrypoint
- architecture/API/database/frontend/validation draft maps
- Second Brain project memory and wisdom notes
- receipt and handoff

## Non-Goals

- No install.
- No clone.
- No provider/model call.
- No source mutation.
- No push or deploy.
- No secret read.
- No live connector or browser bypass.

## Expected Outcome

The repo has a single master plan, a safe first packet, and a clear path to
future build packets without runtime risk.
