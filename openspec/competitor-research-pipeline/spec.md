# OpenSpec - Competitor Research Pipeline

## Requirement

The system shall provide local templates for public-source competitor research and produce a Build Packet for future strategy work.

## Proposal

Use markdown and CSV templates to capture source metadata, score visible competitor signals, summarize SWOT, and convert findings into actionable build tasks.

## Tasks

- Create source selection checklist.
- Create scoring matrix template.
- Create SWOT template.
- Create sample Build Packet.
- Validate templates locally.

## Non-Goals

- No scraping.
- No credentialed access.
- No external provider call.
- No de-anonymization.
- No production mutation.
