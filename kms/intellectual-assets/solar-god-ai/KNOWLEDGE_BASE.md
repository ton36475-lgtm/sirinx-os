# KNOWLEDGE_BASE — Solar Intelligence Core (SIRINX)

> ความรู้แกนกลางที่ AI ตัวไหนก็ควรรู้ก่อนตอบเรื่องโซลาร์ให้ Sirinx
> โครงสร้าง: หัวข้อ → สิ่งที่ต้องรู้ → กับดักที่ห้ามพลาด

---

## K1 — Self-consumption (หัวใจของความคุ้ม)

- โซลาร์คุ้มสุดเมื่อ "ผลิตแล้วใช้เอง" ตอนกลางวัน ไม่ใช่ผลิตแล้วขายคืน
- โปรไฟล์ธุรกิจ/โรงงานที่เดินเครื่องกลางวัน = เคสที่ตรงจุดที่สุด
- บ้านที่ใช้ไฟกลางคืนเป็นหลัก ต้องคุยเรื่องแบตหรือปรับพฤติกรรม — อย่าเชียร์มั่ว

**กับดัก:** อย่าคำนวณ ROI จากกำลังผลิตสูงสุด (kWp) อย่างเดียว — ต้องดู load profile

## K2 — AI Load Control (จุดขายเฉพาะของ SIRINX)

- แนวคิด: สลับ/เลื่อนโหลด (เช่น ปั๊มน้ำ แอร์ เครื่องทำความร้อน) ไปช่วงที่โซลาร์ผลิตได้
- เพิ่ม self-consumption โดยไม่ต้องซื้อแบตเพิ่ม
- สถานะระบบ: อธิบายแนวคิดได้เต็มที่ แต่การควบคุมจริงต้องผ่าน consent + engineer signoff
  (ตอนนี้ Solis = read-only telemetry, simulation ก่อนเสมอ)

**กับดัก:** ห้ามพูดว่าระบบ "ควบคุมให้อัตโนมัติแล้ววันนี้" ถ้า deployment จริงยังเป็น read-only

## K3 — Dynamic ROI

- ROI ไม่ใช่เลขเดียว — เป็นฟังก์ชันของ: บิล, load profile, ขนาดระบบ, ทิศ/มุมหลังคา, ค่าไฟที่ปรับขึ้น
- นำเสนอเป็น "ช่วง + เงื่อนไข" เสมอ ไม่ใช่จุดเดียว
- ข้อมูล input ขั้นต่ำ: บิลย้อนหลัง (1 เดือนพอเริ่มได้, 12 เดือนแม่นสุด), ประเภทมิเตอร์, พื้นที่หลังคา

## K4 — Predictive Maintenance

- Monitor: กำลังผลิตจริง vs คาดหวัง (ตามแดด/ฤดู), อุณหภูมิ inverter, error codes
- แจ้งเตือนเมื่อ underperform ต่อเนื่อง — จับปัญหาแผงสกปรก/เงาบัง/inverter fault ได้เร็ว
- คุยกับลูกค้า: "รู้ก่อนเสีย" ไม่ใช่ "ไม่มีวันเสีย"

## K5 — Solis inverter (ระบบที่เราต่ออยู่)

- เก็บ telemetry: กำลังผลิต, แรงดัน, กระแส, อุณหภูมิ, สถานะ grid
- นโยบายปัจจุบัน: **read-only เท่านั้น** — ห้ามส่งคำสั่งควบคุม/สลับโหลดจริง
  จนกว่าจะมี: customer consent + credential setup + engineer signoff + pilot approval
- ทุกไอเดีย load-balancing ต้องผ่าน simulation ก่อนเสนอ real-world control

## K6 — เรื่องที่ AI ห้ามตอบเชิงลึก (ส่งต่อเสมอ)

- เงื่อนไขสินเชื่อ/leasing/ภาษี
- งานไฟฟ้าแรงสูง, การขออนุญาตการไฟฟ้า (ให้ overview ได้, รายละเอียดส่งวิศวกร)
- การแก้ไข/ดัดแปลงระบบไฟฟ้าเดิมของลูกค้า

### การดูแล asset นี้

- เจอคำถามที่ KB ตอบไม่ได้ระหว่างไลฟ์ → เข้า backlog → เพิ่มหัวข้อ K ใหม่
- ทุกหัวข้อใหม่ต้องมีส่วน "กับดัก" — นั่นคือส่วนที่แพงที่สุดของความรู้
