# REPLY_LIBRARY — Claim-Safe Thai Replies (SIRINX Solar)

> คลัง reply ที่ผ่าน claim guard แล้ว — ใช้เป็น few-shot examples ให้ AI ทุกรุ่น
> หรือ copy ใช้ตรง ๆ ใน approval queue ได้เลย

---

## R1 — "ติดโซลาร์คุ้มไหม"

```text
ขึ้นกับ 3 อย่างหลักครับ: บิลค่าไฟต่อเดือน, ใช้ไฟช่วงกลางวันมากแค่ไหน,
และพื้นที่หลังคา ถ้าบิลเกิน ~3,000 และใช้ไฟกลางวันเยอะ ส่วนใหญ่น่าสนใจครับ
แต่ตัวเลขจริงต้องดูหน้างาน — ส่งบิลมาให้ทีมช่วยคำนวณฟรีได้ครับ
```

## R2 — "กี่ปีคืนทุน"

```text
เคสที่โปรไฟล์การใช้ไฟใกล้เคียงกันมักอยู่ในช่วงหนึ่ง แต่ผมไม่อยากโยนตัวเลขกลาง ๆ
ให้ครับ เพราะขึ้นกับบิล พฤติกรรมใช้ไฟ และขนาดระบบจริง ถ้าส่งข้อมูลเบื้องต้นมา
ทีมคำนวณจากข้อมูลจริงของคุณให้เลยดีกว่าครับ ฟรี ไม่ผูกมัด
```

## R3 — "ลดค่าไฟได้กี่ %"

```text
ตอบแบบรับผิดชอบคือ "แล้วแต่หน้างาน" ครับ ระบบ AI Load Control ของเราช่วยเพิ่ม
สัดส่วนการใช้ไฟจากโซลาร์ให้มากที่สุดเท่าที่พฤติกรรมการใช้ไฟของบ้านคุณเอื้อ
ตัวเลขจริงประเมินได้จากบิลค่าไฟครับ ส่งมาให้ทีมวิเคราะห์ฟรีได้เลย
```

## R4 — "แผงเสีย/เสื่อมไหม ดูแลยังไง"

```text
อุปกรณ์ทุกชิ้นมีการเสื่อมตามอายุครับ จุดที่ระบบเราช่วยคือ Predictive Maintenance —
monitor ประสิทธิภาพแบบ real-time ถ้าแผงหรืออินเวอร์เตอร์ทำงานต่ำกว่าที่ควร
ระบบจะแจ้งก่อนที่จะกลายเป็นปัญหาใหญ่ครับ
```

## R5 — "แพงไหม / ราคาเท่าไหร่"

```text
ราคาขึ้นกับขนาดระบบและหน้างานครับ เลยไม่มีราคากลางที่ยุติธรรมพอจะบอกได้
สิ่งที่ทำให้ได้คือประเมินขนาดระบบที่เหมาะกับการใช้ไฟของคุณก่อน แล้วทีมเสนอ
ตัวเลือกพร้อมตัวเลข ROI จากข้อมูลจริงครับ เริ่มจากส่งบิลค่าไฟมาดูกันฟรีก่อนได้
```

## R6 — ลูกค้าเร่ง/กดดันให้การันตี

```text
ผมการันตีตัวเลขให้ไม่ได้ครับ เพราะทุกหลังใช้ไฟไม่เหมือนกัน — และใครที่การันตี
ได้โดยไม่ดูหน้างาน อยากให้ระวังครับ สิ่งที่ทีมเราทำคือคำนวณจากข้อมูลจริงของคุณ
ให้เห็นตัวเลขก่อนตัดสินใจ โดยไม่มีค่าใช้จ่ายครับ
```

## R7 — Blocked-case fallback (เมื่อ compliance block คำตอบ)

```text
คำถามนี้ขอส่งต่อให้ทีมผู้เชี่ยวชาญตอบโดยตรงดีกว่าครับ เพื่อให้ได้ข้อมูลที่ถูกต้อง
ครบถ้วน ฝากช่องทางติดต่อไว้ หรือแอด LINE ของทีมได้เลยครับ
```

### กติกาใช้คลังนี้

1. ปรับหางเสียง ครับ/ค่ะ ตามผู้พูดจริง
2. อย่า copy ทั้งก้อนถ้าบริบทไม่ตรง — เอาโครง + claim-safety ไป
3. reply ใหม่ที่ผ่าน approval แล้วดี ให้เพิ่มกลับเข้าคลังนี้ (asset โตขึ้นเรื่อย ๆ)
